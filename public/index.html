    How to read a report

    Name and size
    Reports are filed by peptide name and vial size in milligrams. The Sample line shows the name the vial was submitted under, which is sometimes a product code.
    Batch
    The lot code given to the lab. A report is specific to one batch only when it shows a batch code.
    Amount
    The row named after the compound gives the milligrams of it the lab measured in the vial.
    Purity
    The compound's share of everything detected in the sample, as a percentage. It says how clean the material is, not how much is in the vial.
    Verification key
    Each report carries a unique key. Use the verify link, or enter the key on the lab's website, to see the lab's own copy of the report.
    What a report covers
    Only the tests listed in its results. Unless a sterility or endotoxin result appears there, the sample was not tested for it.
